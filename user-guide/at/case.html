用例管理

内容状态：基于代码与页面整理，待产品负责人复核。

用途

用例管理维护平台中的自动化用例视图。用例列表是「禅道用例 + 自动化信息」的只读同步视图，展示自动化状态、代码匹配情况与脚本位置；同时提供套件编排与「未匹配代码用例」的确认入口，是执行前准备用例的主要场所。禅道数据同步本身在系统管理的禅道集成中执行。

入口与前置

  • 入口：自动化测试 → 测试用例 → 用例列表（/at/testcase/list）、套件列表（/at/testcase/suites）、未匹配用例（/at/testcase/unmatched）。
  • 前置：已配置禅道集成与 Git 仓库同步；否则列表为空或仅有平台内用例。
  • 权限：批量执行、标记自动化、删除等按钮受角色权限控制。

界面区域

用例列表左侧为禅道模块树，可按模块筛选；右侧为搜索区与用例表格。表格列包含禅道用例 ID、禅道用例名称、优先级、自动化状态、同步状态、脚本路径、类名、方法名与操作；禅道 ID 可跳转禅道。

📷 截图位：待补充（203 测试数据待脱敏）

点击行可打开用例详情抽屉，展示平台数据与禅道数据，包括名称、优先级、类型、状态、自动化状态、同步状态、框架、脚本路径、类名、方法名、描述、前置条件、测试步骤与标签。「对比禅道」抽屉并排展示平台与禅道字段差异。

套件列表展示套件名称、类型、描述、执行次数、成功率与操作，可编排用例、执行或删除。未匹配用例页列出代码中存在但未与平台用例匹配的记录，含类名、方法名、脚本路径与优先级。

操作步骤

  1. 在用例列表选择模块，或按禅道用例名称、优先级筛选。
  2. 点击用例查看详情，核对脚本路径与禅道信息。
  3. 勾选用例后可批量标记自动化状态、批量对比禅道、批量执行或批量删除。
  4. 单条用例可打开详情、对比禅道或标记自动化；用例列表不提供单条编辑与单条删除。
  5. 在「未匹配用例」中核对脚本信息，点击「已确认」把同步状态改为已确认；该操作不会关联禅道用例。
  6. 在「套件列表」新增套件，填写名称、项目 ID、环境与描述，保存。
  7. 点击套件「编排用例」，从可选用例中挑选（当前主要加载 Web 用例），再点击「执行」。

字段与状态

字段取值
优先级P1–P4
自动化状态待自动化、待调试、已自动化
同步状态已匹配、未匹配、已确认、未同步
用例状态启用、停用、废弃
评审状态待评审、已评审、已驳回
套件类型列表展示后端 type；创建表单不提供类型选择

注意事项与 FAQ

  • 用例列表以禅道用例为主线，脚本路径与类名/方法名来自代码同步；未同步或未匹配时对应列为空。
  • 标记自动化会更新本地状态并按集成配置尝试写回禅道，但不会自动生成脚本；脚本仍需在代码仓库中编写并同步。
  • 未匹配用例的「已确认」只把同步状态改为已确认，不会选择或建立禅道用例关联，也没有批量确认入口。
  • 批量执行使用通用执行弹窗，可选择环境并查看实时进度。
  • 用例列表是只读同步视图，不提供单条编辑；需要变更禅道用例请到禅道维护后重新同步。
  • 用例与套件的可见范围受产品/项目上下文限制，切换产品后列表会变化。
  • 字段与筛选项以实际页面为准。
