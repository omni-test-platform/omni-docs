测试报告

内容状态：基于代码与页面整理，待产品负责人复核。

用途

测试报告中心是全部执行记录的统一入口。它汇总计划执行、任务执行与快速调试的结果，提供详情查看、历史对比、批量取消与批量重跑，并可跳转 Jenkins 托管的 Allure 报告。

入口与前置

  • 入口：自动化测试 → 测试报告（/at/report）。
  • 前置：至少产生过一次执行；查看 Allure 需 Jenkins 报告地址可访问。
  • 权限：取消、重跑、导出等按钮受角色权限控制。

界面区域

页面顶部为统计卡片与筛选区，主体为树形报告列表。列表以执行记录为行，列包含报告 ID、名称、执行环境、分支、版本、状态、通过率、结果、耗时、开始/结束时间、触发方式、触发人、类型与操作；计划行可下钻到阶段执行与任务执行。

报告 ID 前缀表示执行类型：P 为测试计划、T 为测试任务、D 为快速调试。三类记录各自编号，同号不同类属正常。

点击「详情」打开报告详情抽屉，内含基本信息、执行进度、报告汇总、重跑分析四个 Tab；「对比」可将两份报告并排查看差异。

操作步骤

  1. 用名称、类型、状态或执行环境筛选报告。
  2. 点击计划行前的展开按钮下钻阶段与任务；点击任意行「详情」查看该次执行。
  3. 在详情中查看模块统计、失败用例与日志，必要时跳转 Allure。
  4. 勾选两条报告后点击「对比」，查看用例结果的差异。
  5. 勾选一条或多条记录，可批量取消运行中的执行，或批量重跑。
  6. 批量重跑确认时统一选择环境、版本与回填测试单；留空则沿用各自原本的生效值。
  7. 在详情或汇总区导出报告为 HTML/PDF，或推送报告。

字段与状态

字段说明
报告 ID带类型前缀；计划/任务/调试独立编号
结果通过、失败、跳过分档与总数；通过率独立成列
通过率通过用例数 / 已结束用例数，悬停可见分档明细
来源 / 类型测试计划、测试任务、快速调试，下钻后可为测试阶段
状态待执行、执行中、成功、部分失败、失败、取消、异常
耗时从开始到结束的实际时长

注意事项与 FAQ

  • 报告中心的行详情与计划/任务详情使用同一套组件；计划行与任务行可打开四个 Tab 的详情，阶段行当前不提供「详情」入口。
  • 详情抽屉不会自动刷新；运行中的数据需关闭重开或刷新列表。
  • 批量重跑会先弹确认并显示影响条数，不会选中即执行；所选环境与版本对整批生效，不修改任何计划或任务配置。
  • 报告列表没有直接的 Allure 按钮，需进入详情后在基本信息卡打开；Allure 链接由 Jenkins 构建号拼接，浏览器不携带平台登录态，无法打开时检查 Jenkins 匿名只读权限。
  • 「对比」必须正好勾选两条顶层报告；差异为正显示绿色、为负显示红色。
  • 报告中的环境、分支、版本是执行时快照；临时覆盖后显示实际使用值。
  • 用例日志按执行 ID 存放，日志已清理或共享目录未挂载时显示「暂无日志」。
  • 高级筛选的具体字段以实际页面为准。
