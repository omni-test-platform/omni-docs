测试任务

内容状态：基于代码与页面整理，待产品负责人复核。

用途

测试任务是最小的可复用执行单元：它把一组用例、一个执行环境与一组执行参数绑定在一起，可手动执行、定时执行，也可被测试计划引用并参与阶段编排。任务执行产生独立的执行记录与报告。

入口与前置

  • 入口：自动化测试 → 测试执行 → 测试任务（/at/execution/task）。
  • 前置：已有可执行用例；已创建测试环境；选择 Jenkins 通道时需管理员配置可用的 Jenkins 与 job。
  • 权限：新增、编辑、执行、删除按钮受角色权限控制。

界面区域

列表页自上而下为搜索区、操作按钮与任务表格。搜索支持任务名称、类型、状态、优先级与分组；表格列包含 ID、任务名称、执行环境、分支、版本、状态、通过率、用例数、定时配置、上次/下次执行时间、类型、优先级、分组与操作。行操作提供「详情」「执行」与「更多（执行记录、复制、删除）」。

新增/编辑抽屉分四个区块：基本信息、执行参数、定时执行、禅道结果回填。

操作步骤

  1. 点击「新增任务」，填写任务名称、描述与分组。
  2. 选择任务类型（测试套件 / 用例集合 / 自定义）与优先级。
  3. 在执行参数区选择执行环境、分支、调度通道；Jenkins 通道还需选择 Jenkins Job。
  4. 按需填写最大重试、超时、并行数与关联版本；自定义参数为 JSON 对象。
  5. 需要定时执行时打开开关并填写 Cron 表达式。
  6. 需要回填禅道时启用回填，选择测试单来源与提交时机。
  7. 保存后在列表点「用例编排」，选择该任务包含的用例。
  8. 点击「执行」，在确认弹窗中确认环境、版本与测试单后开始执行。

执行参数说明

字段说明
执行环境本次执行使用的环境；未配置时执行前会被拒绝
分支必填；仅 Jenkins 通道在检出代码时生效，本地/SSH 无检出步骤
调度通道本地、SSH 执行器或 Jenkins；决定引擎进程在哪里运行
Jenkins Job调度通道为 Jenkins 时必填
最大重试 / 超时 / 并行数控制单次执行的失败重试、超时与并发
关联版本必填，用于结果归属与趋势分析；回填禅道时与测试单版本校验
自定义参数JSON 对象，按层与计划参数合并，同名键以计划侧为准
禅道回填可选择已有测试单或新建；提交时机分实时与批量

任务详情

任务详情由顶部执行记录选择器与六个 Tab 组成，顺序为：基本信息、执行进度、报告汇总、重跑分析、历史记录、趋势分析。前四个 Tab 随选择器切换为某一次执行的数据；历史记录按服务端分页；趋势分析同时提供按天与按版本两个维度。

注意事项与 FAQ

  • 任务状态只反映手动/调试执行，计划编排触发的执行不回写任务快照，请查看对应计划报告。
  • 执行确认弹窗中的环境、版本与测试单为一次性覆盖，不写回任务配置；执行记录保存实际使用值。
  • 独占环境被占用时任务会排队；共享环境允许多个执行并发。
  • 未选择用例、环境已删除或停用时，执行会被直接拒绝并提示原因。
  • 定时配置与「定时任务」联动；关闭表单中的定时开关不会自动停用已有定时任务，需到定时任务页停用或删除。
