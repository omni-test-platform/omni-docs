执行详情

内容状态：基于代码与页面整理，待产品负责人复核。

用途

执行详情回答「这一次执行到底跑了什么、跑到哪、为什么失败」。计划详情与任务详情内联展示该计划/任务某次执行的数据；报告中心的「详情」抽屉则用于查看任意一条执行记录，二者复用同一套组件。

入口与前置

  • 计划详情、任务详情：顶部执行记录选择器切换目标执行，默认选中运行中/待执行的记录，其次为最新一条。
  • 报告中心：点击计划行或任务行的「详情」，以抽屉形式打开。
  • 预置：执行记录已产生。计划/任务详情页对运行中的执行每 3 秒轮询；报告中心的详情抽屉本身不自动刷新，需关闭重开或刷新列表。

界面区域

执行记录抽屉包含四个 Tab：基本信息、执行进度、报告汇总、重跑分析。计划与任务详情页在此基础上增加历史记录与趋势分析，固定为六个 Tab，顺序为：基本信息、执行进度、报告汇总、重跑分析、历史记录、趋势分析。

📷 截图位：待补充（203 测试数据待脱敏）

基本信息以三列键值网格呈现执行 ID、触发方式、触发人、开始/结束时间、耗时、状态、用例结果、调度通道、Jenkins Job、分支、关联版本与自定义参数；计划执行另有任务结果。执行进度由状态顶栏、分段进度条与明细组成；报告汇总含模块层级统计、KPI 与三张图；重跑分析提供用例选择器。

操作步骤

  1. 在计划/任务详情顶部的选择器中选择一次执行，或在报告中心打开某条记录的「详情」。
  2. 在「基本信息」核对实际使用的环境、分支、版本与调度通道。
  3. 在「执行进度」查看总体进度、阶段/任务状态与逐用例结果；运行中会显示实时耗时与预计剩余。
  4. 点击用例行查看错误信息与执行日志；日志抽屉支持实时更新、跳转到最后与全屏。
  5. 在「报告汇总」查看模块统计与图表，按需导出 Excel 或推送报告。
  6. 在「重跑分析」勾选失败用例或任意子集，确认环境、版本与测试单后重跑。
  7. 需要历史走势时切到「历史记录」或「趋势分析」。

Tab 与状态说明

Tab内容
基本信息执行快照与执行时参数；分支、版本为实际使用值
执行进度计划执行按阶段→任务→用例展示；任务执行展示扁平用例明细
报告汇总L1~L4 模块统计、用例总数/通过/失败/异常/跳过、通过率环、结果分布、问题模块 Top5
重跑分析限定本次执行涉及的用例，支持按结果、优先级、类型、名称/ID 筛选
历史记录一行一次执行，按执行 ID 倒序，服务端分页
趋势分析按天与按版本的执行结果、通过率、耗时走势
状态含义
待执行 / 排队中已受理，等待执行器或环境
执行中正在执行，进度自动刷新
成功 / 部分失败 / 失败按用例结果聚合；Jenkins 构建成功不等于用例全部通过
已取消 / 异常人工中止或执行链路异常

注意事项与 FAQ

  • 执行记录固化环境、分支与版本快照；临时覆盖不写回配置，存量记录可能为空。
  • Jenkins 构建号可跳转；Allure 需匿名只读或统一登录。
  • 用例日志位于共享存储的 reports/case-logs/task-<执行ID>/，未挂载或已清理时显示「暂无日志」。
  • 报告中心可展开计划行；任务行可看详情，阶段行不提供详情入口。
  • 未纳管用例会在进度中提示。
