API 用例

内容状态：基于代码与页面整理，待产品负责人复核。

用途

API 用例页以接口为单位聚合其下的单接口用例，提供分类浏览、审核、自动化状态维护、批量执行与报告查看。它适合按接口维度组织回归范围，也承接 AI 生成的用例。多步骤组合请使用「场景用例」，本页不提供组合编排。

入口与前置

  • 入口：自动化测试 → API → API 用例（/at/api/case）。
  • 前置：已有接口定义与单接口用例；批量执行需要可用的测试环境。
  • 权限：添加、审核、删除、AI 生成与执行受角色权限控制。

界面区域

页面左侧为接口列表树，按功能模块组织并展示接口方法与路径；右侧顶部有三个 Tab：「测试用例」「测试报告」「文档」。

测试用例 Tab 顶部为分类统计与操作按钮：全部、正向、负向、边界值、安全性，以及「AI生成用例」「添加用例」「全部运行」。其下为筛选区（名称、优先级、审核、自动化、状态）与用例表格；表格列包含 ID、用例名称、分组、优先级、审核、自动化、自动化类型、状态与操作。

📷 截图位：待补充（203 测试数据待脱敏）

测试报告 Tab 分「个人」与「共享」；文档 Tab 展示当前接口的请求与响应定义。

操作步骤

  1. 在左侧选择接口，右侧自动加载该接口的用例。
  2. 用分类按钮或筛选条件缩小范围。
  3. 点击「AI生成用例」按策略生成用例；「添加用例」当前仅提示待实现，暂不能新增。
  4. 对单条用例可「运行」「编辑」「审核」或「删除」。
  5. 勾选多条后可批量审核（通过/驳回）、批量删除或批量执行。
  6. 点击「全部运行」执行当前接口下的全部用例。
  7. 在「测试报告」Tab 查看本次或历史执行结果，可切换个人/共享。
  8. 需要查看接口契约时切到「文档」Tab。

字段与状态

字段取值
分组正向、负向、边界值、安全性
优先级P0–P3
审核状态待审核、通过、不通过
自动化状态待自动化、待调试、已自动化
自动化类型测试脚本、配置文件、AI 自然语言；可多选，顺序即执行优先级
执行状态通过、失败、未执行

测试数据集

AI 生成在非「分步生成」模式下可能返回「测试数据集」，弹窗中可编辑一段 JSON 并更新。该数据集只作用于本次生成结果，不是可复用的数据集管理，也不会绑定到已保存用例或场景步骤。分步生成路径下不显示数据集入口。

注意事项与 FAQ

  • API 用例页的「运行」按单条用例执行；批量执行与全部运行会打开统一执行弹窗，可选择环境。
  • 审核状态可在编辑抽屉修改，也可通过批量审核操作。
  • 自动化类型可多选，顺序即执行优先级；未设置时显示为空。
  • 「测试报告」Tab 只展示报告卡片与分页，当前没有报告详情、对比、导出或重跑入口。
  • AI 生成需要先配置模型；生成结果为草稿，需人工审核后再纳入回归。
  • 文档 Tab 是只读展示，修改接口请到「接口管理」。
  • 具体字段与筛选项以实际页面为准。
