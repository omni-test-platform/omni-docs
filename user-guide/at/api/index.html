API 测试

内容状态：基于代码与页面整理，待产品负责人复核。

用途

API 测试子域覆盖从接口定义到场景编排的完整链路：先维护接口，再为接口编写单接口用例，按接口聚合查看与批量执行 API 用例，最后把多个接口步骤编排为场景。它适合接口回归、契约验证和跨接口业务流程测试。

入口与前置

  • 入口：自动化测试 → API（/at/api），默认进入接口管理（/at/api/management）。
  • 前置：已选择产品/项目；已配置接口所属模块；调试或执行时需要可用的测试环境。
  • 权限：新建、导入、删除、生成、执行等操作受角色权限控制。

界面区域

API 子域由五个菜单组成：

菜单路由用途
接口管理/at/api/management维护接口定义、分组、导入与调试
AI生成/at/api/management/ai-generate基于接口生成用例；实际入口通常是接口管理/详情/API 用例中的「AI生成」按钮
单接口用例/at/api/design按接口编写单接口用例
API用例/at/api/case按接口聚合用例、审核、执行与查看报告
场景用例/at/api/scenario多步骤接口场景编排

使用路径

接口管理（定义/导入接口）
  → 单接口用例（为接口编写用例）
  → API 用例（按接口聚合、审核、批量执行）
  → 场景用例（多接口步骤编排）
  → 执行并查看报告

操作步骤

  1. 在「接口管理」新建接口，或用 Swagger/Postman/Har/Jmeter 导入。
  2. 选择接口，打开调试面板验证地址、请求头与请求体。
  3. 在「单接口用例」为接口新建用例，填写请求与预期结果。
  4. 在「API 用例」查看该接口下的用例，按正向/负向/边界/安全分类筛选。
  5. 需要批量覆盖时使用「AI生成用例」，配置生成策略；生成后可按需查看测试数据集。
  6. 勾选用例批量执行，或点击「全部运行」。
  7. 跨接口流程在「场景用例」中拖拽编排步骤并配置断言。
  8. 在「测试报告」或 API 用例页的报告 Tab 查看结果。

注意事项与 FAQ

  • 接口管理与 API 用例都以接口为维度组织；接口删除前应先确认其下用例的处理方式。
  • 单接口用例保存的是请求定义与预期结果，执行时由平台组装为引擎可识别的用例。
  • API 用例页的「文档」Tab 展示接口定义；「测试报告」分个人与共享。
  • AI 生成需要配置模型；未配置时生成入口不可用或提示配置。
  • 场景中的断言支持状态码、响应头、响应体、响应时间与 JSONPath。
  • 具体字段以实际页面为准。
