场景用例

内容状态：基于代码与页面整理，待产品负责人复核。

用途

场景用例把多个接口、脚本、SQL、等待与条件步骤串联成一条业务流程，适合跨接口、需要前置数据或分步断言的测试。它是平台当前实现多步骤组合的主要方式；「API 用例」页只管理单接口用例。

入口与前置

  • 入口：自动化测试 → API → 场景用例（/at/api/scenario）。
  • 前置：已有接口定义或单接口用例；步骤引用接口用例时需先准备对应用例。
  • 权限：新建、编排、删除受角色权限控制；当前页面不提供运行入口。

界面区域

列表页左侧为禅道用例模块树，可按模块筛选；右侧为搜索区与场景表格。列包含 ID、场景名称、状态、执行次数、成功、失败、步骤数与操作，行操作提供「编辑」「编排」「删除」。

📷 截图位：待补充（203 测试数据待脱敏）

新建/编辑使用宽弹窗，分为「基本信息」与「步骤编排」两块。步骤以时间线列表展示，支持拖拽手柄排序；每个步骤显示序号、类型、名称、超时与失败处理，并可「配置」或删除。

操作步骤

  1. 点击「+ 编排场景」，填写场景名称、描述、优先级与项目 ID。
  2. 点击「+ 添加步骤」，在步骤配置抽屉选择步骤类型并填写名称。
  3. 按类型填写接口用例、接口定义、脚本、等待时间、SQL、循环次数或条件表达式。
  4. 设置超时（1–3600 秒）与失败处理：停止、跳过或继续。
  5. 按需添加断言，选择检查项、比较方式、预期值与描述。
  6. 保存步骤后回到场景编辑器，拖拽调整顺序。
  7. 点击「保存场景」落库；需要修改时在列表点击「编辑」或「编排」。

步骤类型

类型说明关键字段
API（引用用例）引用已有单接口用例接口用例 ID、参数覆盖 JSON
API（直接定义）直接选择接口定义接口定义、参数覆盖 JSON
内联脚本执行 Python 脚本脚本内容
等待固定等待等待毫秒数，默认 1000
SQL执行数据库语句SQL 配置 JSON（引擎、地址、语句）
循环重复执行循环次数 1–100
条件按表达式分支条件表达式，如 variables.status_code == 200

断言说明

断言检查项支持状态码、响应头、响应体、响应时间与 JSONPath 提取；比较方式支持等于、不等于、包含、不包含、大于/大于等于、小于/小于等于、正则匹配、为空、不为空、长度等于与 JSONPath 存在。每条断言可填写描述，便于失败定位。

注意事项与 FAQ

  • 场景步骤可覆盖请求参数，但当前没有独立的变量定义、变量提取或数据集管理界面；条件表达式中的变量来自运行时上下文。
  • JSONPath 提取只用于断言，不会把结果写入后续步骤变量。
  • 当前场景页与编辑器都没有「运行」「调试」按钮；执行入口以实际页面为准。
  • 场景状态默认为进行中，编辑器不提供状态选择；标签字段当前不开放编辑。
  • 模块树来自禅道用例模块，切换产品后模块范围会变化。
  • 步骤顺序即执行顺序；失败处理决定单步失败后是停止、跳过还是继续。
