页面管理

内容状态：基于代码与页面整理，待产品负责人复核。

用途

页面管理维护 Web 测试的页面层级。页面是元素的归属容器，也是按页面筛选元素与复用的基础；一个页面可设置基础 URL，便于后续打开与校验。

入口与前置

  • 入口：自动化测试 → Web 测试 → 页面管理（/at/web/page）。
  • 前置：已选择产品/项目。
  • 权限：新增、编辑、删除页面受角色权限控制。

界面区域

页面为左右布局：左侧是功能模块树（展示 L1–L4，按模块统计页面数），根节点为「全部页面」，另有「未分组」；模块维护统一在「环境与配置 → 模块分组」，此处只读。右侧是搜索区与页面表格，表格列包含 ID、页面名称、父页面、基础 URL、元素数、描述与操作；名称前缩进表示层级。

📷 截图位：待补充（203 测试数据待脱敏）

新增/编辑页面使用抽屉，字段包含页面名称、所属模块、父页面、基础 URL、元素快照（JSON）、前置步骤（JSON）与描述。

操作步骤

  1. 在左侧模块树选择模块，或在右侧直接点击新增。
  2. 填写页面名称，选择所属模块；不选父页面即为顶层页面。
  3. 填写基础 URL，例如 https://example.com/login。
  4. 按需填写元素快照与前置步骤 JSON，并填写描述后保存。
  5. 在右侧表格按名称/描述搜索，或展开树定位页面。
  6. 点击「编辑」修改名称、所属模块、父页面、基础 URL 与描述。
  7. 勾选多个页面可批量删除；单条删除需确认。

字段说明

字段说明
页面名称必填，用于树与元素归属
所属模块选择 L4 页面类模块；未选择时归入未分组
父页面可选；为空表示顶层页面
基础 URL页面地址，可留空；元素验证时用于启动浏览器
元素快照 / 前置步骤手工维护的 JSON，仅存储，不参与用例执行
元素数读取页面记录中的元素快照数量，可能与元素管理实际数量不一致
描述页面用途说明

注意事项与 FAQ

  • 页面只负责组织与地址，不决定用例执行顺序；执行顺序由 Web 用例步骤编排决定。
  • 同一页面可挂多个元素；元素在「元素管理」中创建并选择所属页面。
  • 「元素数」来自页面记录中的元素快照，元素增删或迁移不会自动回写，数量可能为 0 或与实际不符。
  • 元素快照与前置步骤当前只存储，不参与用例执行；需要执行的前置动作请写入用例步骤。
  • 调整父页面会改变树层级，但不改变元素本身与用例引用。
  • 删除页面前请确认其下元素是否仍被功能库或用例使用；删除后元素可能失去归属。
  • 基础 URL 用于元素验证；用例运行建议通过「目标环境」注入地址。
  • 页面与功能库组件不是同一概念：页面是 UI 容器，功能库是可复用步骤序列。
  • 具体字段以实际页面为准。
