Web 用例

内容状态：基于代码与页面整理，待产品负责人复核。

用途

Web 用例把元素操作与功能组件编排为浏览器测试流程，并可直接在平台内选择环境、引擎与浏览器运行。它适合登录、表单、列表、下单等端到端 UI 场景。

入口与前置

  • 入口：自动化测试 → Web 测试 → 用例管理（/at/web/case）。
  • 前置：已维护页面与元素；可选地已创建功能库组件；运行前需有可用测试环境与浏览器执行器。
  • 权限：新建、编辑、复制、评审、删除与运行受角色权限控制。

界面区域

页面左侧为模块树与搜索框，右侧为「用例管理」表格。表格列包含 ID、用例名称、步骤数、评审状态与操作；操作提供「编辑」「复制」「通过/驳回（仅待评审）」与「删除」。

选中用例后，表格下方展开步骤编排区：顶部为目标环境、添加步骤、引用组件、保存、执行引擎、浏览器与有头/无头模式；中部为可拖拽的步骤列表；底部显示执行结果。

📷 截图位：待补充（203 测试数据待脱敏）

操作步骤

  1. 点击「+ 新建测试用例」，填写用例名称、描述与基础 URL（可选），先保存。
  2. 保存后点击行内「编辑」，关闭编辑弹窗，再在下方步骤编排区选择目标环境。
  3. 点击「+ 添加步骤」，选择动作类型。
  4. 需要操作元素时选择目标元素；需要复用流程时可引用功能组件。
  5. 展开步骤填写输入值、等待时间、断言类型与预期值、描述。
  6. 拖拽步骤左侧手柄调整顺序。
  7. 选择执行引擎（Playwright / Selenium）、浏览器（Chrome / Firefox / Edge）与有头/无头模式。
  8. 先点击「保存」，再点击「运行」；运行的是已保存的配置。
  9. 查看执行结果、耗时、错误与日志；通过后由评审人评审，后续可被任务/计划引用。

动作类型

动作说明需要的输入
导航 Navigate打开页面目标 URL
点击 Click点击元素目标元素
输入文本 Fill向输入框填写内容目标元素、输入值
获取文本 GetText读取元素文本目标元素
等待元素 WaitFor等待元素出现目标元素、等待时间
悬停 Hover鼠标悬停目标元素
滚动 Scroll滚动页面可选输入值
截图 Screenshot保存截图目标元素可选
固定等待 Wait等待指定时间毫秒数
切换标签 SwitchTab切换浏览器标签标签序号
断言 Assert校验页面或元素元素、断言类型、预期值

断言类型包括文本包含、文本等于、元素可见、元素存在与属性值。

项取值

注意事项与 FAQ

  • 步骤顺序即执行顺序；拖拽后请保存。
  • 功能组件有两种引用方式：工具栏「引用组件」会把组件步骤复制进当前用例；步骤内选择组件则在保存时按最新组件展开。前者不会随组件更新同步。
  • 运行结果卡展示通过/失败/错误、耗时、错误列表与内容区；内容区显示的是生成的执行配置，不是实时引擎日志。
  • 固定等待步骤填写的是毫秒数，但当前执行链路可能按引擎默认等待执行，实际以运行结果为准。
  • 基础 URL 不会持久回显，建议通过「目标环境」注入地址，避免重新编辑后丢失。
  • 当前用例编辑只包含步骤与基础信息，没有数据集、变量或参数化界面。
  • 浏览器执行依赖执行器环境，Playwright 需安装 Chromium 等浏览器；无头模式适合 CI。
  • 具体字段与动作以实际页面为准。
