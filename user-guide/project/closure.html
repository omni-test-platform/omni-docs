项目结项

内容状态：基于代码与页面整理，待产品负责人复核。

用途

项目结项页负责收尾：检查单确认阶段、评审点、门禁、缺陷与版本是否满足结项条件，填写结论与复盘，沉淀文档，结项后归档封存。归档不可逆，之后项目只读。

入口与前置

  • 入口：顶部「项目」→ 左侧菜单「项目结项」，路径 /project/closure。
  • 前置：已在顶栏选择项目；结项前所有阶段应已通过或跳过。
  • 结项、归档、新建复盘与文档需要项目写权限；归档要求项目已结项。

界面区域

页面顶部显示项目名称与当前状态（进行中、已结项、已归档），右侧按状态提供「另存为模板」「结项」「归档」。已归档项目不显示另存为模板；未结项项目不显示归档。

检查单逐项列出检查项、判定条件、实际值与结果；结果为通过、不通过或跳过（无数据）。跳过表示数据不可得，不等于通过或 0。不满足时提示「存在未通过项，暂不可结项」。

复盘记录与交付文档各有一张列表。复盘可新建标题、结论与问题清单；文档可新建标题、类型与内容，类型含需求文档、测试方案、测试报告、发布总结与其他，均可删除。

操作步骤

  1. 查看结项检查单，逐项处理不通过项；数据不可得的项显示跳过及原因。
  2. 检查单显示「可以结项」后点击「结项」，填写结项结论、问题清单，决定是否共享到知识库。
  3. 结项成功后按需新建复盘与交付文档，沉淀过程结论。
  4. 需要复用流程配置时点击「另存为模板」，导出实际阶段、评审点与开关配置。
  5. 确认不再推进后点击「归档」，在二次确认中确认「不可撤销」。

字段与状态

字段/状态说明
阶段完成所有阶段为已通过或已跳过
评审点完成已启用且必须的评审点全部通过；禁用项不计入分母
门禁放行末次门禁校验结果为通过
阻塞缺陷无未闭环的阻塞级缺陷；无数据时跳过
版本发布至少存在一个已发布版本；无版本数据时跳过
结项结论 / 问题清单结项时填写，作为复盘依据
共享到知识库将复盘内容共享到组织级知识库
已结项 / 已归档已结项只能由结项动作产生；归档后不可撤销

注意事项与 FAQ

  • 为什么“确认结项”是灰的？ 检查单仍有不通过项；按明细补齐后再试，跳过项不会阻止结项。
  • 跳过项算通过吗？ 不算。跳过只表示该项数据不可得，避免把“无数据”误读为“零缺陷”。
  • 归档后能撤销吗？ 不能。系统不提供取消归档；需要继续推进请走新的产品/项目。
  • 自动归档是什么？ 「项目配置」开启「结项后自动归档」时，结项成功即归档，不再二次确认；默认关闭。
  • 归档后还能看数据吗？ 可以查看与导出历史，但写操作被拒绝，新建复盘与文档按钮置灰。
  • 另存为模板带走什么？ 当前项目的实际配置，含阶段、评审点与开关；导出前会校验。
