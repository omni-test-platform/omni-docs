质量评估

内容状态：基于代码与页面整理，待产品负责人复核。

六维自动评分、人工评价对照与基线对比，回答「质量好到什么程度」。

用途

  • 用六维评分给出总体量级与红黄绿灯。
  • 按 B 版本记录人工评价，并对照自动评分。
  • 按模块树逐级评价，定位需补测试的模块。
  • 把某时点指标钉成基线，逐项比较改善或退化。

入口与前置

菜单「质量管理 → 质量评估」，下含「质量评分」与「质量基线」。需 qa-analysis 授权。自动评分取当前每日统计与缺陷；人工评价按 B 版本保存；基线可关联已同步版本。

界面区域

📷 截图位：待补充（203 测试数据待脱敏）

质量评分：顶部为综合评分、灯色与计算日期；下方六张维度卡：缺陷密度、通过率、执行率、自动化率、DI、致命占比。逆向指标标注「越低越好」；无数据维度显示「数据不足」，不计 0 分。

评价版本区选择 B 版本，最新 B 版本标注为「产品大版本最终评价」。评价汇总并排展示自动综合、模块人工、整体人工三个口径。模块表展示自身评分、综合分与参与汇总子模块数；整体人工评价可录入评分、结论与建议动作，分差超过 15 分时高亮。

质量基线：左侧为基线列表，右侧为对比结果。表列指标、基线值、当前值、变化、变化率与结论；变化率在基线为 0 时显示「—」，退化项排最前。

操作步骤

  1. 进入「质量评分」，选择要评价的 B 版本。
  2. 先读综合评分与灯色，再逐项看六维；灰色项不参与加权，总分由其余维度归一化。
  3. 点「录入评价」填写评分、结论与建议动作；已有评价可重评。
  4. 在模块表点「评价」，填写评分与问题描述，保存后父模块综合分自动更新。
  5. 进入「质量基线」，点「新建」填写名称、关联版本与说明。
  6. 选择基线查看逐项对比；指标快照不可改。

字段与状态

对象字段/状态说明
评分等级良好 / 需关注 / 需干预按总分阈值着色
六维缺陷密度、通过率、执行率、自动化率、DI、致命占比逆向指标低值得高分
人工评价评分、结论、建议动作百分制，0 分有效
模块汇总自身评分、综合分、子模块数自身与已评子模块的算术平均
基线结论改善 / 持平 / 退化退化项优先

注意事项与常见问题

  • 自动评分会随 B 版本回溯吗？ 不会。自动评分取当前统计，人工评价才按 B 版本记录。
  • 为什么显示「数据不足」而不是 0 分？ 缺数据与表现极差是两件事，按 0 计会给出错误结论。
  • 基线数值能改吗？ 不能。基线是创建当时的快照，需要另一组指标请新建。
  • 分差多少算异常？ 以 15 分为提示阈值。
