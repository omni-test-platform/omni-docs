质量总览

内容状态：基于代码与页面整理，待产品负责人复核。

质量总览是 QA 落地页，回答「现在能发吗、先盯哪几件事」。它只给结论与摘要，细节下钻到监控、分析、评估与门禁页。

用途

  • 在页面顶部给出发布就绪结论，并展示判定依据。
  • 用比率或评分呈现核心质量指标，避免与首页的计数卡重复。
  • 汇总待处理风险，按严重度排序并可点击下钻。
  • 用缩略趋势和最近版本质量，快速判断方向。

入口与前置

菜单「质量管理 → 质量总览」，或直接访问 /qa/overview。需 qa-analysis 授权，并已同步禅道产品与每日统计；否则结论显示「数据不足」。结论复用发布就绪判定，不在本页另立规则。

界面区域

📷 截图位：待补充（203 测试数据待脱敏）

顶部结论条：就绪（绿）、有条件就绪（黄）、不就绪（红）、数据不足（灰）。右侧「查看详情」进入发布就绪页；下方逐项列出判定项的通过、失败或数据不足。

核心指标卡：缺陷 DI、用例通过率、自动化率、最近版本的致命缺陷占比，均带口径提示。

风险预警卡：显示未处理数量，每条含严重度、规则、对象、说明与建议动作。无风险时明确显示「暂无风险项」。

下方依次为：DI 与通过率的趋势缩略图、最近三个真实版本的缺陷对照、缺陷时效（平均解决、平均存续、重开率、超期未解决）。

操作步骤

  1. 确认顶部产品选择器为要评估的产品。
  2. 先读结论条与理由；若显示「数据不足」，展开依据确认缺哪一项。
  3. 查看四张指标卡，点击「刷新」获取最新统计。
  4. 在风险预警中逐条处理，或点「查看全部」进入风险预警列表。
  5. 点击趋势缩略图进入缺陷分析或用例质量；点击版本行进入版本对比。
  6. 需要正式判定时，进入发布就绪复核完整依据。

字段与状态

区域字段/状态说明
结论条就绪 / 有条件就绪 / 不就绪 / 数据不足四态；数据不足不得显示为就绪
指标卡DI、通过率、自动化率、致命占比均带阈值或对比提示
风险预警严重 / 重要 / 轻微按严重度排序，默认展示前 5 条
版本质量版本、缺陷数、致命数、遗留数仅取最近 3 个真实版本
缺陷时效平均解决、平均存续、重开率、超期未解决记录不参与解决时长

注意事项与常见问题

  • 结论与门禁页不一致？ 两页共用同一口径；先刷新并确认产品与禅道范围一致。
  • 指标全是「-」？ 通常是每日统计未同步或当前产品无数据，请先完成禅道同步。
  • 为什么没有「今日缺陷数」？ 该内容由首页承担，本页只放比率与评分。
  • 趋势缩略图只表达形状，精确值进入分析页查看。
