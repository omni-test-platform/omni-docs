效率工具

内容状态：基于代码与页面整理，待产品负责人复核。

用途

效率工具分为「测试工具」和「开发工具」：测试工具覆盖查询、运维、IO、性能、长稳、可靠性、数据工厂；开发工具提供编码、转换、加密、网络、文本等浏览器端小工具。

入口与前置

  • 入口：顶部导航「工具」。其下为「开发工具」和「测试工具」。
  • 前置：License 含 toolkit 功能模块，且当前角色有对应菜单权限。
  • 开发工具不依赖项目、环境或执行器，打开即可使用。

界面区域

「测试工具」按场景分组；「开发工具」是独立工具集。

📷 截图位：待补充（203 测试数据待脱敏）

开发工具页左侧为分类导航，右侧为工具标题、说明和操作区；「全部」页提供搜索、分类分组、收藏心形按钮，「我的收藏」汇总已收藏工具。

操作步骤

  1. 测试工具：从「工具 → 测试工具」选择场景页。当前各页为占位或「敬请期待」，不要按已上线功能安排任务。
  2. 开发工具：进入「工具 → 开发工具」→「全部」，在搜索框输入工具名或分类，或直接选择左侧分类。
  3. 在分类页左侧选择具体工具；页面通过地址中的 tool 参数定位工具，刷新后保持当前工具。
  4. 在输入区粘贴内容或填写参数，结果实时显示或点击执行后显示；按需复制结果。
  5. 点击工具标题右侧的心形图标收藏；到「我的收藏」查看，再次点击取消收藏。

注意事项与 FAQ

  • 测试工具点开是空白？ 这些页面目前是占位页，功能建设中；请以菜单和页面提示为准。
  • 数据工厂能用吗？ 当前显示「敬请期待」，建设中；AT 侧另有数据工厂配置，见用户手册 AT 章节。
  • 开发工具会把数据传到服务器吗？ 多数工具在浏览器本地计算；涉及外部查询的工具以实际实现为准，敏感数据仍应谨慎输入。
  • 生成的密钥、Token 能用于生产吗？ 不能。RSA 密钥、Token、密码等结果仅供调试，生产密钥应在受控环境中生成和保管。
  • 收藏为什么不跨浏览器？ 收藏保存在当前浏览器的本地存储中，不随账号同步；清理浏览器数据会丢失。
  • 工具结果能作为测试结论吗？ 工具只做辅助计算，关键结果需人工复核并留痕。
