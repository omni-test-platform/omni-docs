基础设施

内容状态：基于代码与页面整理，待产品负责人复核。

基础设施维护测试环境与硬件资产，菜单含资源环境、服务器、交换机、IP 地址与数据中心；机房图已并入数据中心的「机房视图」。

用途

  • 登记服务器、交换机的 IP、型号、机柜位置与 SSH 信息。
  • 维护环境、关联服务器、访问地址与标签。
  • 管理 IDC → 机房 → 机柜层级、U 位与 IP 子网。

入口与前置

菜单「资源 → 基础设施」，需 test-platform 授权。资产需先建数据中心与机房，IP 分配需先建子网。服务器表单的凭据用于巡检与执行器连接，以最小权限维护。

界面区域

📷 截图位：待补充（203 测试数据待脱敏）

资源环境：统计环境数、服务器数、在线数与告警数；按名称、责任人、状态、类型搜索；表列 ID、名称、状态、责任人、描述与详情。抽屉含基本信息、访问信息（Base URL、Web URL、用户、FS VIP）、关联服务器与 Testbed XML 预览。

📷 截图位：待补充（203 测试数据待脱敏）

服务器：表列名称、IP、状态、型号、厂商、机柜与 U 位。新增/编辑抽屉含基础信息、SSH 凭据、机柜与 U 位；编辑态另有「端口」「关联环境」Tab。新增时校验 U 位占用。

交换机：字段含名称、速率、状态、型号、厂商、机柜与 U 位，支持增删改。

数据中心：左侧 IDC → 机房树，可增删改；右侧按机房展示「机柜列表」与「机房视图」。机柜列表可卡片/列表切换，显示机柜数、设备数、U 位利用率，支持搜索、类型过滤与新增机柜；点机柜可挂载、移除、迁移设备。机房视图以平面图展示机柜位置。

IP 地址：左侧子网树，右侧五个 Tab——概览、地址分配、IP 查询、子网列表、变更历史。分配页支持表格/网格、单个/批量分配与回收；新增子网需填名称、是否目录、CIDR、网关、VLAN、父级、状态、用途与责任人，CIDR 必须落在父级范围内。

操作步骤

  1. 先建数据中心与机房，再建机柜。
  2. 在服务器/交换机中新增资产，选择机柜与 U 位，填写 SSH 信息。
  3. 在资源环境登记环境、关联服务器并填写访问地址。
  4. 在数据中心选择机房，用机柜列表或机房视图检查占用。
  5. 在 IP 地址建子网并分配地址；回收前确认无业务使用。

字段与状态

对象状态/字段说明
环境online / offline / maintenance / idle在线、离线、维护、空闲
服务器/交换机online / offline / maintenance / idle资产可用状态
机柜available / reserved / online / planned / retired可用、预留、在线、已规划、已弃用
IPin_use / idle / reserved / dhcp已分配、空闲、保留、DHCP

注意事项与常见问题

  • 服务器新增失败？ 常见原因是 U 位占用，按提示调整起始位置或 U 高。
  • 机房图在哪？ 「数据中心 → 选择机房 → 机房视图」。
  • IP 能直接回收吗？ 可以，但会解除绑定；批量回收前确认无业务使用。
  • 环境页能新建吗？ 当前以查看为主，入口以实际页面为准。
