安装

内容状态：基于代码与文档整理，待产品负责人复核。

omni-engine 通常作为依赖安装到虚拟环境，不需要把源码放进测试项目。建议每个测试项目使用独立虚拟环境，避免与其它项目产生依赖冲突；升级引擎也不会改动项目自身的 conf/、testcase/ 与 data/。以下命令均假设当前目录可写，并把占位值替换为实际值。

环境要求

项目要求
Python>= 3.9，推荐 3.11 及以上
操作系统Windows、Linux、macOS
pip随 Python 安装
python -m venv venv

Windows 执行 venv\Scripts\activate，Linux/macOS 执行 source venv/bin/activate。

从 PyPI 安装

pip install omni-engine

PyPI 包只包含框架核心，不包含 demo 演示项目，适合已有 pytest 工程引入。它安装的是发布版本，升级由 pip install --upgrade omni-engine 控制。

从源码安装

源码方式包含 demo，适合本地联调和跟踪上游更新。requirements.txt 覆盖运行与测试所需依赖，pip install -e . 再以可编辑模式注册 omni-engine 包与 CLI 入口。

git clone https://gitee.com/omni-platform/omni-engine.git
cd omni-engine
pip install -r requirements.txt
pip install -e .

后续 git pull 后无需重新安装。

从 wheel 安装

在源码目录构建 wheel（首次使用需先安装 build）：

pip install build
python -m build

产物位于 dist/omni_engine-<version>-py3-none-any.whl。在目标虚拟环境中安装：

pip install /path/to/omni_engine-<version>-py3-none-any.whl

升级时使用 pip install --upgrade 指向新的 wheel。选择建议：快速引入已有工程用 PyPI；需要 demo 或参与引擎开发用源码；需要离线分发、固定版本或内网私有源时用 wheel。团队内应统一引擎版本，避免同一批用例在不同执行机上行为不一致。

可选能力 extras

按需安装，多个 extras 可以组合：

pip install "omni-engine[k8s,chaos,performance,ai,mcp,screenshot,parallel]"
extra依赖用途
k8skubernetes>=28.0K8s 原生测试
chaoskubernetes>=28.0、prometheus-api-client>=0.5Chaos Mesh 与 Prometheus 稳态验证
performancelocust>=2.0Locust 负载测试；k6 后端需本机 k6 二进制
aiopenai>=1.0.0真实 LLM 的 Spec 生成与自愈
mcpfastmcp>=2.0通过 MCP Server 暴露引擎能力
screenshotimageio[ffmpeg]>=2.31、Pillow>=10.0步骤截图与视频/GIF 合成
parallelpytest-xdist>=3.0、pytest-rerunfailures>=13.0并行执行与失败重试

chaos 已包含 kubernetes；performance 的 k6 后端需要另行安装 k6 二进制；screenshot 未安装时，截图与视频合成会降级为仅截图。只安装核心包即可运行 API、Web、CLI、APP 用例。

外部可选依赖

依赖用途说明
Java 11+ 与 Allure CLI生成 Allure 报告Allure 3 需 Node.js，未安装时回退 Allure 2
浏览器与 WebDriverWeb UI 测试脚手架会下载 ChromeDriver
Appium ServerAPP 测试需单独启动 Appium 服务
Node.jsAllure 3、禅道 CLIAllure 3 需 Node.js；禅道 CLI 要求 >= 18，安装 zentao-cli
websocket-clientWS 进度上报未安装时进度上报跳过，不阻塞执行

Allure CLI 可由脚手架下载到项目 bin/allure/，WebDriver 也可用 omni-engine-cli manage --install <browser> 安装。Appium 需单独启动服务；禅道同步依赖 Node.js 与 zentao-cli。

验证安装

omni-engine-cli --version
omni-engine-cli --help
omni-plugin --help

omni-engine-cli 是测试执行入口，omni-plugin 用于创建和管理插件脚手架。两者都能正常输出版本或帮助，说明安装成功。

在测试项目目录创建脚手架：

omni-engine-cli manage --project <project-name>

脚手架会生成 conf/、testcase/、data/、reports/，并下载 WebDriver 与 Allure CLI。若命令找不到，先确认虚拟环境已激活，且 Scripts（Windows）或 bin（Linux/macOS）在 PATH 中。

当前版本注意：manage --project 的实现仍引用已拆分的 demo/ 目录，执行时可能报文件不存在。可复制仓库中的 demo_minio 或 demo_saucedemo 作为项目起点，或手工创建上述目录；manage --install <browser> 仍可用于安装 WebDriver。
