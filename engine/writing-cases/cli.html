CLI 用例

内容状态：基于代码与文档整理，待产品负责人复核。

命令行测试由 CmdRunner 执行。ip 为空时走本地 subprocess，否则通过 SSHManager 连接远端执行。Spec 中的 action: cli 与 action: shell 是同一个适配器，命令来自步骤的 command 字段。

pytest 写法

from omni.common.case import TestCaseBase
from omni.drivers.cmd.cmd_runner import CmdRunner


class TestCommand(TestCaseBase):
    def setup_class(self):
        self.runner = CmdRunner()          # 本地执行

    def test_echo(self):
        result = self.runner.local_run("echo omni-engine", timeout=10)
        self.assertEqual(result.rc, 0, result.stderr)
        self.assertIn("omni-engine", result.stdout)

    def test_remote(self):
        remote = CmdRunner(
            ip="<host>",
            username="<user>",
            password="<password>",
            port=22,
        )
        result = remote.ssh_run("uptime")
        self.assertIn("load average", result.stdout)

主机、账号与密码应从 conf/ 或环境变量读取，不写进用例。远端执行需要目标机可达且 SSH 凭据有效；key_file 可替代密码。local_run 返回的 Result 含 rc、stdout、stderr、elapsed、timeout；run_step 会把它包装成 StepResult，数据在 stdout、stderr、rc 三个键下。

Spec 写法

steps:
  - id: 1
    name: 检查工作目录
    action: cli
    command: 'pwd'
  - id: 2
    name: 等待
    action: sleep
    sleep: 0.5
omni-engine-cli spec run ./specs/cli.yaml

cli/shell 适配器当前直接透传 command，不做变量替换；需要引用变量、循环或复杂断言时，改用 action: script 在内联 Python 中调用 subprocess，或写 pytest 用例。Spec 的验证语法见 Spec。

结果对象

字段说明
rc命令返回码，超时或异常时为负值或进程返回码
stdout标准输出
stderr标准错误
elapsed耗时（秒）
timeout是否因超时被终止
cmd实际执行的命令

断言时优先看 rc 与关键输出，不要只断言“没有异常”。CmdRunner.run_step() 的 success 由 Result.success 决定，个别场景下 stderr 非空但进程未失败，具体语义以当前版本为准。

远程执行

CmdRunner(ip=..., username=..., password=..., port=22) 创建远端执行器；key_file 可替代密码。远端命令通过 SSH 执行，目标机需开放端口并具备相应权限。批量在多个节点执行时，建议按节点创建独立实例，不要把连接对象跨线程共享。敏感凭据从 conf/ 或环境变量注入，必要时使用密钥文件。

工作目录与环境变量

本地命令默认在执行进程的当前目录运行；需要固定目录时，在命令前显式 cd <dir> && ...，或通过项目配置传入绝对路径。命令需要额外环境变量时，可在用例中构造环境并传入，或在执行机上预设；不要把密钥写进命令字符串。跨平台用例注意 Windows 与 Linux 的路径分隔符、shell 内建命令差异。

注意事项

命令按 shell=True 执行，参数拼接与注入风险由用例作者负责；不要在命令中拼接未经校验的外部输入。长任务用 timeout 限制等待时间。仓库 demo_minio/testcase/cli/ 提供了基于 mc 命令的用例结构参考（部分用例为占位实现，运行前需准备 MinIO 环境）。

输出与参考

CmdRunner.run_step() 返回统一的 StepResult，失败信息写入 error；本地命令的返回码与 stderr 语义以当前版本为准。批量执行与并行见执行与编排，命令组合与套件见 CLI 参考。
