常见问题

内容状态：基于代码与文档整理，待产品负责人复核。

版本与部署

官网版本为什么和组件版本不一致？ 官网统一使用产品版本 v1.1.2；omni-server、omni-web、omni-engine 各自有构建号，会随提交递增。对应关系见兼容矩阵，不要用组件构建号判断产品版本。

默认端口是多少？ Web 宿主 9527，API 8888，内嵌 MySQL 3306。端口都可以在部署配置中改；改 API 端口后要同步前端 VITE_SERVICE_BASE_URL 并重新构建。详见部署配置。

为什么没有官方镜像可以直接拉取？ 当前交付方式是源码构建：Compose 从 omni-server / omni-web 源码构建镜像，或使用 deploy.py 推送 systemd + Nginx。没有官方镜像仓库，首次构建耗时取决于网络与机器。详见部署运维。

升级需要停机吗？ 需要。数据库迁移、二进制替换与服务重启都在维护窗口内完成；先备份，再按升级与回滚执行。升级前在测试环境走通执行与回调闭环。

权限与执行

登录后接口返回 401 或 403 怎么办？ 401 是未登录或 Token 失效，检查 x-token 请求头、JWT 密钥是否在重启后变化；403 是已登录但 Casbin 拒绝，检查角色是否绑定了对应 API 与按钮权限。权限模型见权限管理。

任务一直停在“排队中”是什么原因？QUEUED 表示平台已受理但还没拿到执行资源：可能等本地并发槽、Jenkins 执行器，或独占环境被其他执行占用。检查执行容量、Jenkins 节点与环境租约。

回调签名校验失败怎么排查？ 确认服务端与执行机设置了同一个 OMNI_CALLBACK_SECRET，且签名是对原始请求体字节计算；代理若改写请求体或编码，会导致签名不一致。字段与示例见回调协议。

Allure 报告打不开？ 平台只保存报告地址，报告文件由 Jenkins 或执行机托管。检查 Jenkins 匿名只读权限、报告路径与共享存储挂载；详见Jenkins 执行通道。

Skills 与全流程自动化

Skills 体系和平台里的自动化测试是什么关系？ Skills 体系在“生产侧”：把需求/页面变成测试方案、禅道用例、自动化脚本与报告，并保持用例 ID 可追溯；平台 AT 在“管理侧”：负责用例库、任务/计划、环境、Jenkins 调度与质量门禁。两者通过 omni-platform-case-push 衔接，不是替代关系。详见Skills 全流程自动化。

Skills 能完全无人值守吗？ 不承诺。阶段执行与产物流转是自动的，但 PRD/设计初稿、AI 生成用例、禅道写入与平台推送保留人工评审或确认。当前定位是“阶段自动化 + 人工门”，不是 L3 无人值守。详见核心机制。

为什么页面元素必须实测，不能按截图写 selector？ 臆造的 selector 会在自动化阶段变成一批失败用例，修复成本远高于在方案阶段多打开一次页面。技能要求在方案中记录实测 selector、抓取时间与验证结论；环境不可达时显式标记“未验证”，不能把推测写成已验证。

禅道回写后 用例ID 为空怎么办？ 先核对用例名称是否与禅道侧完全一致、是否已成功导入产品、产品 story 模块路径是否与 csv“所属模块”一致。当前回写按用例名称匹配，默认标题唯一；同名用例需要先消除歧义。详见安装与运行。

数据库与授权

支持哪些数据库？SQLite 能用于生产吗？ 服务端支持 MySQL、PostgreSQL、SQLite、Oracle、SQL Server；默认与推荐 MySQL 8.0。SQLite 只用于本地开发，不适合多用户生产。迁移脚本按 MySQL/MariaDB 语法编写，切换数据库需单独验证。

License 过期或换机后怎么办？ License 绑定机器码与有效期，换机或硬件变化后原文件失效，需要重新签发并导入。License 管控始终启用，本地开发可用 -tags licensefree 跳过。详见授权管理。

文档

页面里的“截图位”和“内容状态”是什么意思？ 仅空数据/通用界面使用了 203 测试环境截图；涉及真实环境、任务与质量数据的页面保留截图位，待脱敏后再补。draft 表示内容完整但待产品负责人复核，placeholder 表示功能未上线或整页建设中。两者都不代表功能已验收。

文档与页面不一致时以哪个为准？ 以当前代码与配置为准。发现不一致可通过仓库 issue 反馈，并附上页面路径、版本与复现步骤。
