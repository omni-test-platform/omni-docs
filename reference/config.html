zaplevel、format、director、retention-day日志目录与级别

db-listalias-name、type、连接参数多数据源别名，运行期按别名获取
redis / redis-listaddr、password、db、use-cluster可选；JWT 黑名单与缓存可用
mongohosts、database、认证参数可选
local 及各云存储path、bucket、endpoint、密钥按 oss-type 选择
corsmode、whitelist同源反代通常无需放开
emailhost、port、secret、from、to通知邮件

disk-list / monitormount-point、disk-threshold、check-interval-minutes磁盘告警

服务端入口默认加载工作目录下的 .env.production.yaml，用 -c <path> 覆盖；OMNI_CONFIG 与 gin 模式回退仅在未提供 -c 时生效。

前端环境变量

变量作用
VITE_BASE_URL部署子路径，必须以 / 结尾
VITE_APP_TITLE / VITE_APP_DESC站点标题与描述
VITE_AUTH_ROUTE_MODEstatic 或 dynamic；生产用 dynamic
VITE_ROUTE_HOME登录后首页 route key
VITE_ROUTER_HISTORY_MODEhistory / hash / memory
VITE_SERVICE_BASE_URLAPI 基地址；开发指 8888，生产用 /api
VITE_SERVICE_SUCCESS_CODE成功业务码，默认 0
VITE_SERVICE_LOGOUT_CODES / MODAL_LOGOUT_CODES / EXPIRED_TOKEN_CODES登出、弹窗登出、Token 过期码
VITE_STATIC_SUPER_ROLE静态路由模式下的超级角色
VITE_HTTP_PROXY / VITE_MOCK_ENABLE开发代理与 mock 开关

前端变量在构建时固化，修改后必须重新构建；运行时不能通过改 Nginx 配置改变 API 地址。

引擎 settings.ini

常用段：[PRODUCT]、[LOGGER]、[WEB]、[REPORT]、[ALLURE]、[DATABASES]、[HEADERS]、[AI]、[JENKINS]、[ZENTAO]、[PLATFORM]、[API]、[SCREENSHOT]、[NOTIFY]。优先级为环境变量 > 项目级 conf/settings.ini > 框架默认 omni/config/settings.ini。

常用环境变量：OMNI_WEB_ENGINE、OMNI_WEB_BROWSER、OMNI_WEB_HEADLESS、OMNI_WEB_LOCALE、OMNI_ALLURE_VERSION、OMNI_ALLURE_BIN、OMNI_SCREENSHOT_*、OMNI_WORKERS、OMNI_DIST、OMNI_RERUNS、OPENAI_*、OMNI_CALLBACK_*、ZENTAO_*。

敏感项

jwt.signing-key、system.encrypt-key、数据库密码、OMNI_CALLBACK_SECRET、AI API Key、Jenkins/禅道凭据都属于敏感配置，不得提交到版本库或写入文档。system.encrypt-key 一旦写入过凭据就不能更换，否则历史密文无法解密。
